# Breast Cancer Classification Using Logistic Regression

This project uses Logistic Regression to classify breast cancer cases based on diagnostic features from the provided `cancer.csv` dataset.

The project covers data preprocessing, feature selection, label encoding, normalization, train-test splitting, model training, and prediction using Scikit-learn.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Dataset

The project includes the `cancer.csv` dataset used for training and testing the classification model.

## Workflow

1. Load and explore the dataset
2. Remove unnecessary columns
3. Encode the diagnosis labels
4. Separate features and target
5. Normalize the input features
6. Split the data into training and testing sets
7. Train a Logistic Regression classifier
8. Generate predictions on unseen test data

## Goal

The goal of this project is to apply a classical Machine Learning classification algorithm to a real-world medical dataset and gain practical experience with data preprocessing, feature scaling, model training, and binary classification.
